Analyse du matchmaking de Clash Royale (Hadoop)

Un projet de big data qui vérifie, sur 35 millions de parties, si le matchmaking de Clash Royale est vraiment aléatoire, en comparant les fréquences observées aux fréquences théoriques.

Type
Projet académique, big data
Volume
Jusqu'à 35 millions de parties
Stack
Hadoop MapReduce, Java, Python

Voir le dépôt GitHub

Ce que contient le projet

  • Traitements Hadoop MapReduce écrits en Java et exécutés sur un cluster.
  • Nettoyage des données et calcul de statistiques.
  • Scripts Python pour l'analyse des résultats et les visualisations.
  • Benchmarks de performance sur des jeux de données allant de 100 000 à 35 millions de parties.
